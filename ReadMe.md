## Description
Le projet SecMyMail vise à développer un greffon pour le logiciel de messagerie Thunderbird, via l’API WebExtension. Ce greffon doit permettre d’améliorer la sécurité de ce logiciel de Messagerie en identifiant visuellement (couleurs, étiquette/marqueur dans sujet) les messages suspects (e.g. messages contenant des URLs non officielles et non listées par l’utilisateur, comme *.gouv.fr), de mettre un message d’alerte à l’utilisateur lorsque celui-ci déclenche un téléchargement d’un fichier depuis un lien suspect défini dans un courriel. Ce greffon devra également faire apparaître de manière visuelle les courriels qui ne proviennent pas des contacts de l’utilisateur, ou ne respectant pas un domaine (e.g. univ-ubs.fr). Les courriels marqués pourront être filtrer avec le mécanisme de filtre de Thunderbird et être déplacés dans un répertoire spécifique. Ce greffon permettra ainsi de limiter le risques utilisateurs liés aux courriels d’hameçonnage.
